HASE Gruppe – Etappe 1

1. ZIP entpacken.
2. GitHub Repository öffnen: https://github.com/hp-hafner-creator/dresden2026
3. Add file > Upload files anklicken.
4. Alle entpackten Dateien und Ordner hineinziehen: index.html, styles.css, app.js, sw.js, manifest.webmanifest, assets, icons.
5. Commit changes anklicken.
6. Nach ca. 1–3 Minuten öffnen: https://hp-hafner-creator.github.io/dresden2026/
7. Am iPhone in Safari öffnen > Teilen > Zum Home-Bildschirm.
